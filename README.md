# privacy-policy-digikar

エムスリーデジカル（DigiKar）／デジスマ向け Chrome 拡張機能の**プライバシーポリシー公開リポジトリ**。
1 リポジトリに複数の拡張機能のポリシーを同居させているため、ファイルと対象拡張の対応は下表のとおり。

公開URL（ルート）: https://kumakuma-libe.github.io/privacy-policy-digikar/

## ファイル一覧

| ファイル | 対象の拡張機能 | 公開URL |
|---|---|---|
| `index.html` | **デジカル尿検査自動計算**（digikar-urine-calc） | https://kumakuma-libe.github.io/privacy-policy-digikar/ |
| `doc-maker.html` | **デジカル書類作成くん**（digikar-doc-maker） | https://kumakuma-libe.github.io/privacy-policy-digikar/doc-maker.html |
| `ishi-irekaekun.html` | **DigiKar 医師入れ替えくん**（digikar-ishi-irekaekun） | https://kumakuma-libe.github.io/privacy-policy-digikar/ishi-irekaekun.html |
| `digisma-yoyaku-chosei-kun.html` | **デジスマ予約調整くん**（digisma-yoyaku-chosei-kun） | https://kumakuma-libe.github.io/privacy-policy-digikar/digisma-yoyaku-chosei-kun.html |
| `digisma-wakuire.html` | **デジスマ枠入れくん**（digisma-wakuire） | https://kumakuma-libe.github.io/privacy-policy-digikar/digisma-wakuire.html |

## メンテナンス時の注意

- 拡張機能の実装（`manifest.json` の権限・外部送信先・保存するデータ）を変更したら、
  対応するポリシーも同時に更新し、**最終更新日と対象バージョンを書き換える**こと。
- ファイルを追加・削除・改名した場合は、**本 README の表**と、
  Chrome ウェブストアの各拡張の「プライバシーポリシーURL」欄も合わせて更新すること。
